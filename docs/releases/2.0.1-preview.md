## Alder.Avalonia 2.0.1-preview

此预览版面向 .NET 11，依赖 Avalonia 12.2.0。

```sh
dotnet package add Alder.Avalonia --version 2.0.1-preview
```

[NuGet 包](https://www.nuget.org/packages/Alder.Avalonia/2.0.1-preview) · [在线 Gallery](https://luoverse.github.io/Alder.Avalonia/) · [组件文档](https://github.com/LuoVerse/Alder.Avalonia/blob/v2.0.1-preview/docs/COMPONENTS.md)

### 新增控件

- `AlderTag` 和 `AlderTagGroup` 支持可移除标签及标签分组。
- 新增 `AlderTextField`、`AlderFieldset`、`AlderForm`，以及可独立使用的 `AlderDescription`、`AlderFieldError` 和 `AlderErrorMessage`。
- 新增 `AlderMenu`、`AlderTreeView` 和 `AlderTimePicker`。TimePicker 支持分段编辑、弹层确认与取消，并在独立的滚动区域显示小时、分钟和秒列的细滚动条。

### 输入与交互

- 日期和时间控件可在 AXAML 中设置 `DisplayFormat`。可编辑控件可另外设置 `ParseFormat`，用于粘贴和整段文本的精确解析。绑定值继续使用 `DateOnly?`、`TimeOnly?` 和 `AlderDateRange?`。
- TreeView 的子树高度与箭头同步过渡。菜单栏和上下文子菜单加了短合成入场，紧凑导航菜单和编辑器候选弹层加了淡入。动效遵循 `AlderMotion.Reduced`。
- 修复 Cell Slider 拖动时的背景闪烁、File Tree 滚动到尾部不完整，以及输入尾部按钮进入 Tab 顺序的问题。改进 Splash Window 交接时的窗口激活与焦点。

### Gallery 与验证

- 侧栏按用途分为 12 个分组，更新英文和简体中文目录，增加表单、标签、菜单、树和日期时间格式示例。
- NativeAOT 烟测使用只加载 `AlderTheme` 的宿主，包含深浅主题全控件渲染、交互与像素回归。

### 桌面 Gallery

Release 附件提供 Windows、macOS 和 Linux 的 x64 与 ARM64 自包含包。macOS 打开 `Alder Gallery.app`，Windows 和 Linux 运行对应的 Gallery 可执行文件。macOS 包使用临时签名。可使用 `shasum -a 256 -c SHA256SUMS.txt` 校验附件。
