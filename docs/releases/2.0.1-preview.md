## Alder.Avalonia 2.0.1-preview

**English** · [简体中文](2.0.1-preview.zh-CN.md)

This preview targets .NET 11 and depends on Avalonia 12.2.0.

```sh
dotnet package add Alder.Avalonia --version 2.0.1-preview
```

[NuGet package](https://www.nuget.org/packages/Alder.Avalonia/2.0.1-preview) · [Online Gallery](https://luoverse.github.io/Alder.Avalonia/) · [Component catalog](../COMPONENTS.md)

### New controls

- `AlderTag` and `AlderTagGroup` support removable tags and tag collections.
- Added `AlderTextField`, `AlderFieldset`, and `AlderForm`, along with standalone `AlderDescription`, `AlderFieldError`, and `AlderErrorMessage` controls.
- Added `AlderMenu`, `AlderTreeView`, and `AlderTimePicker`. TimePicker offers segmented editing, confirmation and cancellation in its popup, and separate slim scrollbars beside the hour, minute, and second options.

### Input and interaction

- Set `DisplayFormat` on date and time controls directly in AXAML. Editable controls also accept `ParseFormat` for exact parsing of pasted or whole-text input. Bound values continue to use `DateOnly?`, `TimeOnly?`, and `AlderDateRange?`.
- TreeView animates subtree height and the chevron together. Menu bar dropdowns and context submenus gained a short composition entrance. Compact navigation menus and editor suggestion popups fade in. These animations honor `AlderMotion.Reduced`.
- Fixed flickering during Cell Slider drags, incomplete scrolling to the end of File Tree, and trailing input buttons appearing in the tab order. Improved window activation and focus when Splash Window hands off to the next window.

### Gallery and verification

- The sidebar has 12 groups organized by purpose. Both the English and Simplified Chinese catalogs include new examples for forms, tags, menus, trees, and date and time formats.
- The NativeAOT smoke host loads only `AlderTheme` and covers public control rendering in Light and Dark, interactions, and pixel regressions.

### Desktop Gallery

Release assets include self-contained builds for Windows, macOS, and Linux on x64 and ARM64. Open `Alder Gallery.app` on macOS or run the Gallery executable on Windows and Linux. The macOS builds use ad hoc signing. Use `shasum -a 256 -c SHA256SUMS.txt` to verify the assets.
