## Alder.Avalonia 2.0.0

目标框架为 .NET 11，依赖 Avalonia 12.2.0。

```sh
dotnet package add Alder.Avalonia --version 2.0.0
```

[NuGet 包](https://www.nuget.org/packages/Alder.Avalonia/2.0.0) · [在线 Gallery](https://luoverse.github.io/Alder.Avalonia/) · [组件文档](https://github.com/LuoVerse/Alder.Avalonia/blob/v2.0.0/docs/COMPONENTS.md)

### 升级指南

大多数组件的 `Icon` 属性及相应的 Avalonia 属性类型从 `Geometry?` 扩展为 `object?`。升级后请重新编译依赖 Alder.Avalonia 1.x 的应用和库。已有 AXAML `Geometry` 资源仍可直接赋给 `Icon`。C# 代码若需要按几何图形处理读取结果，可使用 `component.Icon is Geometry geometry`。引用 `StyledProperty<Geometry?>` 的自定义绑定也需更新为 `StyledProperty<object?>`。

组件根据主题和 `Size` 为图标分配空间。引用相应的图标包后，可在组件的 `Icon` 属性中使用 `MaterialIconExt` 或 Fluent `SymbolIcon`。窗口标题栏等窗口类图标继续使用内置 Geometry。[三种图标写法与命名空间](https://github.com/LuoVerse/Alder.Avalonia/blob/v2.0.0/docs/COMPONENTS.md#图标属性)

### 组件与 Gallery

- 新增或扩展 Image View、Workflow Editor、Bloom Menu、Expandable Action Bar、Overflow Actions、Transitioning Content 和 Splash Window 示例。
- Gallery 增加 Geometry、Material 和 Fluent 的尺寸对照示例，改进预览与源码的加载，并补充组件使用指南。
- 改进下拉框和弹层关闭后的键盘焦点处理，修复多种控件的黑色外框、双边框及高 DPI 渲染问题。
- 提供可选的 `WithAlderPuHuiTiFont()`，为应用配置内置阿里巴巴普惠体。其他宿主可继续使用自己的字体配置。

### 性能

- Agenda 按日期更新事件并复用现有控件。命令面板与自动完成对大集合使用并行的本地筛选，保留原有匹配规则与顺序。
- 富文本编辑复用字形与 JSON 片段。Table 和 DataGrid 减少单元格模板开销。给 Table 设置固定 `RowHeight` 可进一步延迟创建横向视口外的单元格。
- 优化 File Tree、图表、Map、Image View、Workflow Editor、Timeline、Kanban、Carousel 和 Chip 的渲染及交互路径。
