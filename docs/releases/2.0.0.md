## Alder.Avalonia 2.0.0

**English** · [简体中文](2.0.0.zh-CN.md)

This release targets .NET 11 and depends on Avalonia 12.2.0.

```sh
dotnet package add Alder.Avalonia --version 2.0.0
```

[NuGet package](https://www.nuget.org/packages/Alder.Avalonia/2.0.0) · [Online Gallery](https://luoverse.github.io/Alder.Avalonia/) · [Component catalog](../COMPONENTS.md)

### Upgrading

Most components now declare their `Icon` properties and corresponding Avalonia properties as `object?`. Rebuild any applications and libraries compiled against Alder.Avalonia 1.x. Existing AXAML `Geometry` resources can still be assigned directly to `Icon`. Use `component.Icon is Geometry geometry` when C# code needs to process a geometry. Update custom bindings that reference `StyledProperty<Geometry?>` to use `StyledProperty<object?>`.

The theme and `Size` determine the space reserved for an icon. Reference the corresponding icon package to supply `MaterialIconExt` or a Fluent `SymbolIcon`. Window chrome continues to use built-in geometry icons. [Icon examples and namespaces](../COMPONENTS.md#icon-properties)

### Components and Gallery

- Added or extended examples for Image View, Workflow Editor, Bloom Menu, Expandable Action Bar, Overflow Actions, Transitioning Content, and Splash Window.
- Added Gallery size comparisons for Geometry, Material, and Fluent icons, improved preview and source loading, and added usage guides.
- Improved keyboard focus after closing dropdowns and popups. Fixed dark outlines, double borders, and high-DPI rendering issues across several controls.
- Added the optional `WithAlderPuHuiTiFont()` to configure the bundled Alibaba PuHuiTi font. Hosts can continue using their own font configuration.

### Performance

- Agenda updates events by date and reuses existing controls. Command and autocomplete parallelize local filtering for large collections while preserving matching rules and result order.
- Rich Text Editor reuses glyphs and JSON fragments. Table and Data Grid reduce cell template overhead. A fixed `RowHeight` lets Table defer creating cells outside the horizontal viewport.
- Improved rendering and interaction in File Tree, charts, Map, Image View, Workflow Editor, Timeline, Kanban, Carousel, and Chip.

### Desktop Gallery

| Platform | ARM64 | x64 |
| --- | --- | --- |
| Windows | `win-arm64.zip` | `win-x64.zip` |
| macOS | `osx-arm64.zip` (Apple Silicon) | `osx-x64.zip` (Intel) |
| Linux | `linux-arm64.tar.gz` | `linux-x64.tar.gz` |

All desktop builds are self-contained. Run `Alder.Avalonia.Gallery.exe` on Windows, open `Alder Gallery.app` on macOS, or run `Alder.Avalonia.Gallery` from a graphical Linux session. The macOS builds are ad hoc signed and have yet to be notarized by Apple. Use `shasum -a 256 -c SHA256SUMS.txt` to verify the release assets.

### Release verification

The Release build completed without warnings and all 447 tests passed. The macOS ARM64 NativeAOT smoke test used the published NuGet package. All six desktop archives were checked for file format, target architecture, and SHA-256.
